# Foundation contract and source disposition

The fresh Rust foundation is published in the existing Sinex repository (foundation PR2696). It is not a deployed release. The design basis is the Polylogue/Sinex specification revision `0740d4190ffae435c240ed822f2cab84d3cda913`: Sinex purpose/model/storage/surfaces, schema decision, workspace plan and the joint bootstrap inventory. This document records the implemented subset; the broader design remains unimplemented until its own acceptance.

The predecessor tracked source tree at `c997df89764aa47d624355ae04fbe65e6f9a2bfa` was replaced by the published foundation. LICENSE, .gitattributes, .editorconfig, rustfmt.toml, the existing nixpkgs pin (with obsolete lock inputs removed) and all predecessor .beads routing/configuration documents are retained. At foundation publication, task routing retained its predecessor owner; [current task routing](../../.beads/README.md) follows the separately authorized transition. All predecessor source crates, xtask, examples, CI, hooks, NixOS modules, schemas, cached product declarations and architecture prose are removed from the target tree. Their history remains in Git and the externally preserved pre-rewrite recovery baseline. This is an explicit whole-tree disposition; no directory name was treated as proof that its contents lacked value. No external task database, deployment input, live capture or service state was changed.

Supported foundation: query-free canonical schema control; real reader/writer database permissions; writer connection owned by a bounded admission task; config validation/schema export, status/version/catalog through actual daemon and CLI; controlled startup/shutdown. Synthetic admission is exercised by an internal integration test, not exposed as a public source or RPC.

The [Atuin subset](atuin.md) now connects read-only source acquisition, retained rows, observations, private writer admission and real query/show/trace clients. The [retained Atuin replay subset](retained-replay.md) adds bounded replacement through the same writer and source parser. The [reversible exclusion subset](reversible-exclusion.md) hides one stable raw Atuin occurrence through the same durable writer/action owner and allows explicit undo without implicit admission. The [indexed retrieval subset](indexed-retrieval.md) connects a restricted projection owner and six actual MCP read tools to shared queries and canonical shell evidence. The [selected shell grouping subset](shell-fusion.md) adds retained append-only extended zsh records and bounded Atuin/zsh grouping. The [Chromium subset](chromium.md) connects configured visits and persisted downloads, consistent custody, reduced value reads and periodic physical bases to public raw clients. Other capture sources, general fusion, general replay, confirmed delivery, analytics, sealed lifecycle and the native library remain unavailable. Composition outlines are not registered capabilities. The minimum bootstrap inventory and all M1 obligations remain open wherever actual tests have not established them.

The event-storage boundary includes the full event-row column shape and structural constraints in `core.events` and `reflection.events`, real UUIDv7 Timescale hypertables, explicit compression/sparse-index settings, occurrence side tables and logical archive topology. The synthetic writer maintains its coordinate and material-count rows in the same transaction. Unknown time stays unknown; known source times and producer clocks retain their declared semantics. Definition checks compare actual indexes, triggers, functions, views and Timescale settings against the protected catalog captured while applying the Rust declarations.

This is not a complete target schema or general admission engine. Physical SQLite snapshot revisions and derivation registries, general payload validation, the full privacy lifecycle, ordered schema changes and remaining target packages still need implementation. Earlier preparation-schema fingerprints are refused, not silently upgraded or reset. Direct schema tests of derived rows, archiving and compression prove that storage boundary; they do not register those operations as supported API routes. Atuin uses its integer nanosecond timestamp as intrinsic producer evidence. The separate synthetic proof route continues to emit Unknown.

Shared content storage uses Polylogue’s owner-released `hashed-blobs-v0.1.1`, including its non-mutating Reader capability. The Git dependency replaces the provisional vendor snapshot entirely. Cargo.lock binds the real remote tag to the owner commit; the Nix package additionally binds the fetched source hash. The shared crate introduces no Sinex service or product backend dependency. No private absolute path or vendor fallback is a product dependency.
